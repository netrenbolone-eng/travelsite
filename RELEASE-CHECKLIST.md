# Перед публикацией

## Обязательные настройки компании

- [ ] В `src/config/site.ts` заменить демонстрационные `origin`, телефон, WhatsApp, Telegram, email, адрес, часы работы, карту, платёжную ссылку и социальные ссылки.
- [ ] Заменить `lotusroute.example` и другие демонстрационные ссылки на рабочие домены и каналы компании.
- [ ] Проверить цены, длительность и состав туров в `src/data/tours.ts`.
- [ ] Заменить демонстрационные отзывы в `src/data/reviews.ts` подтверждёнными отзывами или временно отключить блок.
- [ ] Заменить демонстрационный рейтинг и количество гостей в `src/config/site.ts` либо удалить эти значения.
- [ ] Утвердить текст политики конфиденциальности для фактического оператора сайта.

## Форма заявок

- [ ] Создать `.env.local` из `.env.example`.
- [ ] Добавить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в локальную среду и в секреты хостинга. Не помещать секреты в репозиторий.
- [ ] Отправить тестовую заявку на каждом языке (`/ru`, `/en`, `/vi`) и проверить доставку в Telegram.
- [ ] Проверить, что ссылки WhatsApp, Telegram и телефон ведут на реальные каналы компании.

## Контент и изображения

- [ ] Убедиться, что выбранные фотографии соответствуют фактическим турам и регионам.
- [ ] Сохранить `CREDITS.md` вместе с проектом и проверить условия используемых изображений перед коммерческой публикацией.
- [ ] Проверить отображение hero-видео на мобильном и настольном экранах. Исходные видео и poster лежат в `public/videos/`.

## Сборка

```bash
npm ci
npm run lint
npm run build
npm start
```

Локальный визуальный обзор: откройте `preview.html`. Он показывает макет главной страницы; интерактивную production-версию следует запускать командами выше.
